Create the image-forward recipe card per CONTEXT.md decisions:

**Styling:**
- White background with rounded corners (rounded-xl)
- Subtle shadow (shadow-sm), hover shadow (hover:shadow-md)
- Smooth transition on hover

- Dark overlay appears on image
- "View Recipe" text shown

- If imageKey exists, construct URL from R2 public bucket (use env var or config)

    imageKey: string | null
  }
}>()

**Difficulty color coding:**
