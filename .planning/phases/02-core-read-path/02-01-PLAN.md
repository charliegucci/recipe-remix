  <name>Task 1: Add recipe tables to Drizzle schema</name>
  <files>
    server/db/schema.ts
  </files>
  <action>
Extend the existing schema.ts (which has auth tables) with recipe tables:

1. Add `recipes` table with fields:
   - `id`: text primary key (UUID for stable identity)
   - `title`: text not null
   - `description`: text
   - `ingredients`: text not null (JSON array: [{name, quantity, unit}])
   - `instructions`: text not null (JSON array of strings)
   - `cuisineTags`: text default '[]' (JSON array)
   - `dietaryTags`: text default '[]' (JSON array)
   - `cookTime`: integer (minutes)
   - `difficulty`: text ('easy' | 'medium' | 'hard')
   - `imageKey`: text (R2 object key, nullable)
   - `source`: text not null default 'curated' ('curated' | 'ai_generated')
   - `featured`: integer mode:boolean default false
   - `createdAt`: integer mode:timestamp with default

2. Add `recipeCategories` junction table for efficient category filtering:
   - `id`: text primary key
   - `recipeId`: text not null references recipes.id with onDelete cascade
   - `category`: text not null (the cuisine category)

3. Add index on recipeCategories.category for efficient WHERE queries (use drizzle-orm index syntax)

Use the existing patterns from the auth tables (integer mode:timestamp for dates, text for IDs).
  </action>
  <verify>
Run `npx drizzle-kit generate` - should create a new migration file in server/database/migrations/ with CREATE TABLE statements for recipes and recipe_categories.
  </verify>

  </done>
