Create the recipe detail page per CONTEXT.md and RESEARCH.md:

**SSR Data Fetching:**
```typescript
const route = useRoute()
const { data: recipe, error } = await useFetch(`/api/recipes/${route.params.id}`)

if (error.value) {
  throw createError({
    statusCode: error.value.statusCode || 500,
    statusMessage: error.value.statusMessage || 'Recipe not found'
  })
}
```

**Page Layout (Hero banner per RESEARCH.md recommendation):**
1. Hero image section (full-width, aspect-[16/9] or aspect-[4/3])
   - If imageKey exists, show image
   - Graceful fallback if no image (colored background with title)
   - Gradient overlay with title at bottom
2. Recipe metadata bar: cook time, difficulty, cuisine tags, dietary tags
3. Description section
4. Ingredients section with IngredientChecklist component
5. Instructions section with StepCard components (one per step)

**Component Integration:**
- Pass recipe.id as recipeId to IngredientChecklist and StepCard
- Pass recipe.ingredients to IngredientChecklist
- Map recipe.instructions to StepCard with stepNumber and totalSteps

**Responsive Layout:**
- Single column on mobile
- On desktop (lg:), consider side-by-side for ingredients and steps
- Or keep single column for focused reading

**Metadata Display:**
- Cook time: icon + "30 min"
- Difficulty: colored badge (green/yellow/red)
- Cuisine tags: pill badges
- Dietary tags: pill badges (if any)

**SEO:**
```typescript
useHead({
  title: `${recipe.value.title} | Recipe Remix`,
  meta: [
    { name: 'description', content: recipe.value.description }
  ]
})
```

**Navigation:**
- Back button or link to home page
- Breadcrumb optional (Home > Recipes > Recipe Title)
