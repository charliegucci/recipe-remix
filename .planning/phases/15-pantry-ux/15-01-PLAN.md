  <name>Task 1: Create ingredient emoji mapping utility</name>
  <files>app/utils/ingredientEmoji.ts</files>
  <action>
Create `app/utils/ingredientEmoji.ts` exporting a `getIngredientEmoji(name: string, category?: string): string` function.

**Per-ingredient map:** Build a `Record<string, string>` mapping ~120+ common ingredient names (lowercase) to their closest Unicode food emoji. Cover all 305 seeded ingredients where a recognizable emoji exists. Examples:
- produce: onion→🧅, garlic→🧄, tomato→🍅, potato→🥔, carrot→🥕, bell pepper→🫑, broccoli→🥦, spinach→🥬, lettuce→🥬, cucumber→🥒, mushroom→🍄, avocado→🥑, lemon→🍋, lime→🍋, ginger→🫚, corn→🌽, apple→🍎, banana→🍌, orange→🍊, strawberry→🍓, blueberry→🫐, pineapple→🍍, coconut→🥥, peach→🍑, pear→🍐, grape→🍇, watermelon→🍉, cherry→🍒, kiwi→🥝, mango→🥭
- protein: chicken breast→🍗, ground beef→🥩, steak→🥩, bacon→🥓, eggs→🥚, shrimp→🦐, salmon→🐟, crab→🦀, lobster→🦞, tofu→🧈, squid→🦑, octopus→🐙, turkey breast→🦃, duck→🦆
- dairy: butter→🧈, milk→🥛, cheese (all varieties)→🧀, yogurt→🫙
- grains: bread→🍞, rice→🍚, pasta→🍝, tortilla→🫓, pizza dough→🍕, oats→🥣
- spices: salt→🧂, chili/pepper varieties→🌶️, garlic powder→🧄, herbs→🌿
- condiments: honey→🍯, olive oil→🫒, ketchup→🍅, soy sauce→🥢
- baking: chocolate→🍫, cookie→🍪
- canned: olives→🫒, beans→🫘
- nuts_seeds: peanuts→🥜, chestnuts→🌰

**Category fallback map:** For ingredients without a specific emoji:
- produce→🥬, protein→🍖, dairy→🧀, grains→🌾, spices→🧂, condiments→🫙, baking→🧁, canned→🥫, nuts_seeds→🥜

**Function logic:**
1. Normalize name to lowercase
2. Check exact match in per-ingredient map
3. If no match, try first word of name (e.g., "chicken breast" → check "chicken")
4. If still no match, use category fallback (if category provided)
5. Final fallback: "🍽️"

Also export `getCategoryEmoji(category: string): string` for cases where only category is available.

**PantryList.vue changes:**

The PantryList receives `items: PantryItem[]` where each item has `{ id, name }`. It does NOT receive category. Two options:
- Option A: Extend PantryItem interface to include optional `category` field and pass it from `usePantry` composable
- Option B: Use `getIngredientEmoji(name)` without category — the name-based lookup will cover most cases, with "🍽️" fallback for rare misses

**Choose Option B** (simpler, no composable changes needed). If coverage is poor, category can be added later.

Update the pantry item pill (the `v-for` div) to include the emoji before the name:
```
<span class="text-lg leading-none mr-1" aria-hidden="true">{{ getIngredientEmoji(item.name) }}</span>
<span class="text-sm font-medium">{{ item.name }}</span>
```

Import `getIngredientEmoji` from `~/utils/ingredientEmoji`.

The emoji should be `text-lg` to appear as a small visual thumbnail. Use `aria-hidden="true"` since emojis are decorative (the name text is the accessible label). The pill already uses `flex items-center gap-2` so spacing should work naturally. Adjust gap if needed.
