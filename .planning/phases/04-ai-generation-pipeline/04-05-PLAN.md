**app/composables/useGenerate.ts:**

Export `useGenerate()` composable that manages generation state with polling and resume support:

State:
- `status: Ref<'idle' | 'generating' | 'validating' | 'imaging' | 'complete' | 'error'>`
- `generatedRecipe: Ref<any | null>` (the full recipe object returned from API)
- `errorMessage: Ref<string>`
- `generationId: Ref<string | null>` -- persisted to localStorage via VueUse `useLocalStorage('lastGenerationId', null, { initOnMounted: true })` so it survives navigation

Actions:
- `generate(ingredients: string[], cuisines: string[], restrictions: string[]): Promise<void>`
  - Set status to 'generating'
  - Call `$fetch('/api/recipes/generate', { method: 'POST', body: { ingredients, cuisines, restrictions } })`
  - On success: store generationId from response, set status to 'complete', store recipe in generatedRecipe
  - After receiving recipe, trigger image generation: call `$fetch(\`/api/recipes/${recipeId}/image\`, { method: 'POST' })` (this is the PRIMARY reliable path per Plan 03). Update generatedRecipe.imageKey on success. This call is fire-and-forget from the UI perspective (don't block the complete state).
  - On error: set status to 'error', parse error body for user-friendly message, store in errorMessage
  - Handle specific error codes: 401 -> "Please log in to generate recipes", 400 -> show validation message, 422 -> show specific rejection reason
- `reset(): void` - Reset all state to initial values, clear lastGenerationId from localStorage
- `resumeGeneration(): Promise<void>` -- called on composable init / page mount
  - Check if generationId exists in localStorage
  - If yes, poll GET /api/recipes/generation/:id
  - If status is 'completed': load the recipe into state, set status to 'complete'
  - If status is 'generating' or 'validating': set status accordingly, start polling every 2 seconds until complete or failed (max 60 seconds / 30 polls, then show timeout error)
  - If status is 'failed': set status to 'error', show errorMessage
  - If 404 or poll timeout: clear generationId, reset to idle
- `retryImageGeneration(recipeId: string): Promise<void>`
  - Call `$fetch(\`/api/recipes/${recipeId}/image\`, { method: 'POST' })`
  - Update generatedRecipe.imageKey on success
