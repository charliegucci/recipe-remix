**server/api/recipes/generate.post.ts:**

Import logAnalyticsEvent from ../../utils/analytics. Add analytics logging at these points:
1. After successful recipe save: `logAnalyticsEvent(db, { eventType: 'recipe_generated', userId, recipeId, metadata: { cuisines, ingredientCount: ingredients.length } })`
2. On generation failure (any catch block): `logAnalyticsEvent(db, { eventType: 'recipe_generation_failed', userId, metadata: { error: errorMessage, cuisines } })`
3. After successful image generation (in the .then callback): `logAnalyticsEvent(db, { eventType: 'image_generated', userId, recipeId })`
4. On image generation failure: `logAnalyticsEvent(db, { eventType: 'image_generation_failed', userId, recipeId })`

All logAnalyticsEvent calls are fire-and-forget (no await needed, the function handles its own errors).
