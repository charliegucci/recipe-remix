<task type="auto">
  <name>Task 1: Extend database schema with Phase 3 tables</name>
  <files>server/db/schema.ts</files>
  <action>
Add 6 new table definitions to the existing schema.ts file. Keep all existing tables (users, sessions, accounts, verifications, recipes, recipeCategories) unchanged.

Import `primaryKey` from `drizzle-orm/sqlite-core` (add to existing import).

Add these tables following the exact patterns from the research doc:

1. `ingredients` - Curated ingredient master list:
   - id: text PK
   - name: text not null
   - category: text not null (produce, protein, dairy, grains, spices, condiments, baking, canned, frozen, beverages)
   - commonNames: text not null default '[]' (JSON array of search aliases)
   - createdAt: integer timestamp
   - Index on name

2. `pantryItems` - User's pantry:
   - id: text PK
   - userId: text FK -> users.id cascade
   - ingredientId: text not null
   - ingredientName: text not null
   - addedAt: integer timestamp
   - Index on userId, index on ingredientId

3. `userDietaryRestrictions` - User dietary preferences:
   - id: text PK
   - userId: text FK -> users.id cascade
   - restriction: text not null (vegetarian, vegan, gluten-free, dairy-free, nut-free)
   - createdAt: integer timestamp
   - Index on userId, unique composite index on (userId, restriction)

4. `userFavorites` - Junction table, composite PK:
   - userId: text FK -> users.id cascade
   - recipeId: text FK -> recipes.id cascade
   - createdAt: integer timestamp
   - primaryKey on (userId, recipeId)
   - Separate indexes on userId and recipeId

5. `userRecipeHistory` - Viewing/generation history:
   - id: text PK
   - userId: text FK -> users.id cascade
   - recipeId: text FK -> recipes.id cascade
   - viewedAt: integer timestamp
   - Index on userId, index on viewedAt

6. `userRecipeReviews` - Ratings and notes:
   - id: text PK
   - userId: text FK -> users.id cascade
   - recipeId: text FK -> recipes.id cascade
   - rating: integer not null (1-5)
   - review: text (optional)
   - createdAt: integer timestamp
   - updatedAt: integer timestamp
   - Unique composite index on (userId, recipeId), index on recipeId

Use `integer('...', { mode: 'timestamp' })` for all date fields (established pattern). Use `$defaultFn(() => new Date())` for auto-timestamps. Use `{ onDelete: 'cascade' }` on all FK references.
  </action>
