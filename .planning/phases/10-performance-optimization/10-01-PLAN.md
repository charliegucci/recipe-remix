<task type="auto">
  <name>Task 2: Install @nuxt/image and replace all img tags with NuxtImg</name>
  <files>
    nuxt.config.ts
    package.json
    app/components/RecipeCard.vue
    app/components/FeaturedCarousel.vue
    app/components/RecipeCategorySection.vue
    app/pages/recipe/[slug].vue
    app/pages/history.vue
    app/pages/generate.vue
  </files>
  <action>
1. Install @nuxt/image: `npm install @nuxt/image`
2. Add `@nuxt/image` to the modules array in nuxt.config.ts.
3. Configure the image module in nuxt.config.ts:
   ```typescript
   image: {
     quality: 80,
     formats: ['webp'],
     screens: {
       xs: 320,
       sm: 640,
       md: 768,
       lg: 1024,
       xl: 1280
     }
   }
   ```
   Note: Do NOT use the cloudflare provider — R2 serves raw images without transformation. Use the default ipx provider which works with any image URL.

4. Replace all `<img>` tags with `<NuxtImg>` in these files:

   **RecipeCard.vue** (card images — below fold, lazy):
   - Replace `<img :src="imageUrl" ...>` with:
     ```vue
     <NuxtImg
       :src="imageUrl"
       :alt="recipe.title"
       loading="lazy"
       format="webp"
       sizes="sm:100vw md:50vw lg:400px"
       class="w-full h-48 object-cover"
     />
     ```

   **FeaturedCarousel.vue** (hero images — above fold, eager):
   - Replace `<img>` with:
     ```vue
     <NuxtImg
       :src="getImageUrl(recipe.imageKey)"
       :alt="recipe.title"
       loading="eager"
       fetchpriority="high"
       format="webp"
       sizes="sm:100vw md:100vw lg:1200px"
       class="..."
     />
     ```
   - Only the currently visible slide should be eager; others can be lazy.

   **RecipeCategorySection.vue** (category cards — mostly below fold, lazy):
   - Same pattern as RecipeCard, `loading="lazy"`.

   **recipe/[slug].vue** (recipe detail hero — above fold, eager):
   - Replace `<img>` with:
     ```vue
     <NuxtImg
       :src="..."
       :alt="recipe.title"
       loading="eager"
       fetchpriority="high"
       format="webp"
       sizes="sm:100vw md:100vw lg:800px"
       class="..."
     />
     ```

   **history.vue** (history thumbnails — lazy):
   - Replace `<img>` with `<NuxtImg>`, `loading="lazy"`, `sizes="sm:80px"`.

   **generate.vue** (generated recipe image — lazy):
   - Replace `<img>` with `<NuxtImg>`, `loading="lazy"`.

5. Preserve all existing CSS classes, alt text, and conditional rendering (v-if) on images.
6. Run `npm run build` to verify no errors.
  </action>
  <verify>
- `npm run build` completes without errors
- `grep -r '<img ' app/` returns zero results (all native img tags replaced)
- NuxtImg used in all 6 files with appropriate loading strategy (eager for hero, lazy for cards)
  </verify>

</task>
