<task type="auto">
  <name>Task 3: Setup Tailwind CSS with mobile-first configuration</name>
  <files>
    tailwind.config.ts
    assets/css/main.css
    nuxt.config.ts
  </files>
  <action>
    1. Install Tailwind CSS:
       ```bash
       npm install -D tailwindcss @tailwindcss/vite
       ```

    2. Create tailwind.config.ts:
       ```typescript
       import type { Config } from 'tailwindcss'

       export default {
         content: [
           './components/**/*.{vue,ts}',
           './layouts/**/*.vue',
           './pages/**/*.vue',
           './app.vue'
         ],
         theme: {
           extend: {
             // Mobile-first: default breakpoints are sufficient
             // sm: 640px, md: 768px, lg: 1024px, xl: 1280px
           }
         },
         plugins: []
       } satisfies Config
       ```

    3. Create assets/css/main.css:
       ```css
       @tailwind base;
       @tailwind components;
       @tailwind utilities;

       /* Base mobile-first styles */
       html {
         @apply text-base antialiased;
       }

       body {
         @apply min-h-screen bg-gray-50 text-gray-900;
       }
       ```

    4. Update nuxt.config.ts to include CSS:
       ```typescript
       css: ['~/assets/css/main.css'],
       vite: {
         plugins: [tailwindcss()]
       }
       ```
       Import tailwindcss from '@tailwindcss/vite' at top of config.

    5. Update app.vue to test Tailwind:
       ```vue
       <template>
         <div class="min-h-screen flex items-center justify-center p-4">
           <div class="text-center">
             <h1 class="text-2xl font-bold md:text-4xl">Recipe Remix</h1>
             <p class="text-gray-600 mt-2">Foundation loading...</p>
           </div>
         </div>
       </template>
       ```
  </action>

    - Resize browser: layout should remain centered without horizontal scroll.
  </verify>
  <done>
