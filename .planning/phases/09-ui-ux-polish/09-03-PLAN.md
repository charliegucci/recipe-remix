  <name>Task 1: Add mobile hamburger menu to AppHeader and fix touch targets on navigation</name>
  <files>

  <action>
The current AppHeader has desktop nav (`hidden md:flex`) but no mobile nav. Mobile users have no way to access navigation links other than direct URL entry.

Add a mobile hamburger menu:

1. Add a `mobileMenuOpen` ref: `const mobileMenuOpen = ref(false)`

2. Add a hamburger button visible only on mobile (`md:hidden`), placed before the auth section in the header flex row:
   ```html
   <button
     @click="mobileMenuOpen = !mobileMenuOpen"
     class="md:hidden min-w-[44px] min-h-[44px] flex items-center justify-center rounded-lg text-gray-600 hover:text-gray-900 hover:bg-gray-100 transition-colors"
     :aria-label="mobileMenuOpen ? 'Close menu' : 'Open menu'"
     aria-expanded="false"
   >
     <!-- Hamburger icon when closed -->
     <svg v-if="!mobileMenuOpen" class="w-6 h-6" fill="none" stroke="currentColor" viewBox="0 0 24 24">
       <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M4 6h16M4 12h16M4 18h16" />
     </svg>
     <!-- X icon when open -->
     <svg v-else class="w-6 h-6" fill="none" stroke="currentColor" viewBox="0 0 24 24">
       <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M6 18L18 6M6 6l12 12" />
     </svg>
   </button>
   ```

3. Add the mobile menu panel below the header bar (inside the header element, after the main flex row):
   ```html
   <!-- Mobile Navigation Menu -->
   <nav v-if="mobileMenuOpen" class="md:hidden border-t border-gray-200 py-2">
     <NuxtLink to="/" class="block px-4 py-3 min-h-[44px] text-gray-700 hover:bg-gray-50 transition-colors" @click="mobileMenuOpen = false">Home</NuxtLink>
     <NuxtLink to="/pantry" class="block px-4 py-3 min-h-[44px] text-gray-700 hover:bg-gray-50 transition-colors" @click="mobileMenuOpen = false">My Pantry</NuxtLink>
     <NuxtLink to="/generate" class="block px-4 py-3 min-h-[44px] text-gray-700 hover:bg-gray-50 transition-colors" @click="mobileMenuOpen = false">Generate</NuxtLink>
     <NuxtLink to="/favorites" class="block px-4 py-3 min-h-[44px] text-gray-700 hover:bg-gray-50 transition-colors" @click="mobileMenuOpen = false">Favorites</NuxtLink>
     <NuxtLink to="/history" class="block px-4 py-3 min-h-[44px] text-gray-700 hover:bg-gray-50 transition-colors" @click="mobileMenuOpen = false">History</NuxtLink>
   </nav>
   ```

4. Close mobile menu on route change: Add `watch(useRoute(), () => { mobileMenuOpen.value = false })` or use the `@click` approach above (already included).

5. Fix desktop nav link touch targets: Add `min-h-[44px] flex items-center` to each desktop nav `<NuxtLink>` so they also meet touch target requirements.

6. Fix auth section buttons: Ensure Sign In, Sign Up, Sign Out, Create Account buttons all have `min-h-[44px]` and adequate padding (`px-4 py-2` minimum).

Audit all interactive elements and fix touch targets + spacing consistency. Read each file first, then apply targeted fixes:

**StarRating.vue:**
- Each star button must have `min-w-[44px] min-h-[44px] flex items-center justify-center` to ensure tappable area is adequate. Stars may currently be small SVGs (w-5 h-5 = 20px). Wrap each in a button or add padding to expand the tap area.
- Use `p-2` padding around stars to expand touch area.

**CuisineSelector.vue:**
- Each cuisine option button/tag must have `min-h-[44px]` and `px-4 py-2` minimum padding.
- Ensure gap between items is consistent: `gap-3` for the grid/flex container.

**IngredientAutocomplete.vue:**
- The input field should have `min-h-[44px]` (standard form input height for mobile).
- Autocomplete dropdown items should have `min-h-[44px] px-4 py-2` for easy tapping.
- The "Add" button (if present) should have `min-h-[44px]`.

**StepCard.vue:**
- The step card is already tappable (the whole card). Ensure it has `min-h-[44px]`.
- The checkbox area should be at least 44px tap target.

**ServingScaler.vue:**
- The +/- buttons must have `min-w-[44px] min-h-[44px]`. These are likely small icon buttons that need padding expansion.
- Use `flex items-center justify-center` on the buttons.

**PantryList.vue:**
- Remove/delete buttons for pantry items must have `min-w-[44px] min-h-[44px]`.
- Ensure consistent spacing between list items: `gap-3` or `space-y-3`.

**DietaryRestrictions.vue:**
- Toggle/checkbox elements must have `min-h-[44px]` tap targets.
- Consistent spacing between options.

**login.vue and register.vue:**
- Form inputs: `min-h-[44px]` (usually already met with `py-3` or `py-2.5` + text).
- Submit buttons: `min-h-[44px] w-full` with `py-3`.
- Links (forgot password, switch to register/login): ensure `min-h-[44px]` tap area with adequate padding.
- Consistent spacing: use `space-y-4` for form fields, `space-y-6` for sections.

**pantry.vue:**
- Ensure page layout uses consistent spacing: `space-y-6` for major sections, `space-y-4` for sub-sections.
- Review overall padding consistency with other pages.

**General spacing rules to enforce:**
- Tight (gap-2, p-2): within small inline groups
- Default (gap-3, p-3, mb-3): related elements, component inner padding
- Medium (gap-4, mb-4): between component sections
- Large (gap-6, mb-6, py-6): between major page sections
- XL (gap-8, mb-8, py-8): page-level spacing, hero areas
