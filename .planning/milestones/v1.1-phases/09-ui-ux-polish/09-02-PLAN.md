**Generation progress time estimate:**

1. In `app/composables/useGenerate.ts`:
   - Add a `startTime` ref: `const startTime = ref<number | null>(null)`
   - Set `startTime.value = Date.now()` at the beginning of the `generate()` function (right after `status.value = 'generating'`)
   - Set `startTime.value = null` in the `reset()` function
   - Export `startTime` in the return object

2. In `app/components/GenerationProgress.vue`:
   - Add prop: `startTime: number | null` (default null)
   - Add a reactive elapsed time using `useIntervalFn` from VueUse (already installed), or a simple `setInterval` in `onMounted`:
     ```
     const elapsed = ref(0)
     let timer: ReturnType<typeof setInterval> | null = null

     watch(() => props.startTime, (val) => {
       if (val) {
         elapsed.value = 0
         timer = setInterval(() => {
           elapsed.value = Math.floor((Date.now() - val) / 1000)
         }, 1000)
       } else if (timer) {
         clearInterval(timer)
         timer = null
       }
     }, { immediate: true })

     onUnmounted(() => { if (timer) clearInterval(timer) })
     ```
   - Compute estimated remaining: typical generation is 30-60 seconds. Use step-based estimate:
     - `generating` step: ~20 seconds
     - `validating` step: ~10 seconds
     - `imaging` step: ~15 seconds
     - Based on current step and elapsed time, show "About X seconds remaining..." or "Almost done..." if estimate <= 0
   - Add below the steps list (before error section): a `<p>` with class `text-sm text-gray-500 text-center mt-2` showing the time estimate. Only show when status is not 'complete', 'error', or 'idle'.

3. In `app/pages/generate.vue`:
   - Import `startTime` from `useGenerate()` destructuring
   - Pass `:start-time="startTime"` to `<GenerationProgress>`

**Page transitions:**

4. In `nuxt.config.ts`, add inside the existing config object:
   ```
   app: {
     pageTransition: {
       name: 'fade',
       mode: 'out-in'
     }
   }
   ```

5. In `app/assets/css/main.css`, add page transition CSS:
   ```css
   /* Page transitions */
   .fade-enter-active,
   .fade-leave-active {
     transition: opacity 200ms ease-in-out;
   }

   .fade-enter-from,
   .fade-leave-to {
     opacity: 0;
   }

   /* Respect reduced motion preference */
   @media (prefers-reduced-motion: reduce) {
     .fade-enter-active,
     .fade-leave-active {
       transition-duration: 1ms !important;
     }
   }
   ```
  </action>

Run `npx nuxi typecheck` to verify no TypeScript errors. Run `npx nuxi build` to verify the build succeeds. Check that `nuxt.config.ts` has `app.pageTransition` and `main.css` has `.fade-enter-active`.
  </verify>
  <done>GenerationProgress shows elapsed time and estimated remaining seconds during AI generation. Page transitions use a 200ms fade between routes. Reduced motion preference is respected.</done>
