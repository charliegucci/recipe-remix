  <action>
Create GitHub Actions workflow for automatic production deployments on push to main.

**File: `.github/workflows/deploy.yml`**

```yaml
name: Deploy to Production

on:
  push:
    branches: [main]

jobs:
  deploy:
    name: Deploy to Cloudflare Pages
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build application
        run: npm run build

      - name: Deploy to NuxtHub
        env:
          NUXT_HUB_PROJECT_KEY: ${{ secrets.NUXT_HUB_PROJECT_KEY }}
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
        run: npx nuxthub deploy --production
```

**Key points:**
- Triggers only on push to `main` (not on PRs)
- Uses `npx nuxthub deploy --production` for production deployments
- Requires two secrets (user will need to add these in GitHub repo settings):
  - `NUXT_HUB_PROJECT_KEY`: From NuxtHub project settings
  - `CLOUDFLARE_API_TOKEN`: From Cloudflare dashboard (API Tokens page)
- Runs `npm ci` for deterministic installs
- Builds before deploying to catch build errors early

<task type="auto">
  <name>Create preview deployment workflow</name>
  <files>.github/workflows/preview.yml</files>
  <action>
Create GitHub Actions workflow for preview deployments on pull requests.

**File: `.github/workflows/preview.yml`**

```yaml
name: Deploy Preview

on:
  pull_request:
    branches: [main]

jobs:
  preview:
    name: Deploy Preview
    runs-on: ubuntu-latest

    permissions:
      pull-requests: write  # Allow commenting on PR

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build application
        run: npm run build

      - name: Deploy preview
        id: deploy
        env:
          NUXT_HUB_PROJECT_KEY: ${{ secrets.NUXT_HUB_PROJECT_KEY }}
          CLOUDFLARE_API_TOKEN: ${{ secrets.CLOUDFLARE_API_TOKEN }}
        run: |
          OUTPUT=$(npx nuxthub deploy --preview 2>&1)
          echo "$OUTPUT"
          # Extract preview URL from output (format: "Deployed to https://...")
          PREVIEW_URL=$(echo "$OUTPUT" | grep -o 'https://[^ ]*pages.dev' | head -1)
          echo "preview_url=$PREVIEW_URL" >> $GITHUB_OUTPUT

      - name: Comment preview URL on PR
        if: steps.deploy.outputs.preview_url != ''
        uses: actions/github-script@v7
        with:
          script: |
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: `## 🚀 Preview Deployment Ready\n\n**URL:** ${{ steps.deploy.outputs.preview_url }}\n\nTest this preview before merging to production.`
            })
```

**Key points:**
- Triggers on pull requests targeting `main`
- Uses `npx nuxthub deploy --preview` for preview deployments
- Captures preview URL from deploy output
- Posts preview URL as PR comment for easy access
- Requires `pull-requests: write` permission for commenting
- Same secrets as production workflow
