  <context>
NuxtHub offers two deployment methods:

1. **NuxtHub Admin (recommended for first deploy)**
   - Web UI at https://admin.hub.nuxt.com
   - Automatically creates Cloudflare resources (D1, KV, R2)
   - One-click GitHub integration
   - Handles bindings and secrets via dashboard
   - No local Cloudflare CLI setup needed

2. **NuxtHub CLI (`npx nuxthub deploy`)**
   - Command-line deployment
   - Requires Cloudflare account linked locally
   - More control over resource naming
   - Good for CI/CD workflows (use in Plan 02)

For initial production deployment, NuxtHub Admin is recommended because it automatically provisions all Cloudflare resources and handles binding configuration.

## Step 1: Update .env.example with production variables

Add production environment variables to .env.example (for documentation):

```bash
# Cloudflare (populated at deploy time)
# CLOUDFLARE_ACCOUNT_ID=
# CLOUDFLARE_D1_DATABASE_ID=

# Better Auth
BETTER_AUTH_SECRET=your-secret-key-min-32-chars-long
BETTER_AUTH_URL=http://localhost:3000

# Production (NuxtHub will set these)
NUXT_PUBLIC_AUTH_URL=https://your-app.pages.dev
```

## Step 2: Deploy to NuxtHub

**If selected: nuxthub-admin**

1. Go to https://admin.hub.nuxt.com
2. Sign in with GitHub
3. Click "New Project"
4. Select "Import from GitHub" → choose `Recipe Remix` repository
5. Configure project settings:
   - **Project name**: `recipe-remix` (or your preferred name)
   - **Production branch**: `main`
   - **Build command**: `npm run build` (auto-detected)
   - **Install command**: `npm install` (auto-detected)
6. Under "Resources", enable:
   - **Database (D1)**: Create new database named `recipe-remix-db`
   - **KV**: Create new namespace named `recipe-remix-cache`
   - **Blob (R2)**: Create new bucket named `recipe-remix-images`
   - **AI**: Enable Workers AI (checkbox)
7. Under "Environment Variables", add:
   - `BETTER_AUTH_SECRET`: Generate with `openssl rand -base64 32`
   - Leave `NUXT_PUBLIC_AUTH_URL` blank for now (will update after first deploy)
8. Click "Deploy"
9. Wait for build to complete (~2-3 minutes)
10. Note the deployed URL (e.g., `https://recipe-remix-xyz.pages.dev`)

**If selected: nuxthub-cli**

1. Install NuxtHub CLI: `npm install -g nuxthub`
2. Authenticate: `npx nuxthub login`
3. Link Cloudflare account: `npx nuxthub link` (follow prompts)
4. Create resources manually:
   ```bash
   npx wrangler d1 create recipe-remix-db
   npx wrangler kv:namespace create recipe-remix-cache
   npx wrangler r2 bucket create recipe-remix-images
   ```
5. Deploy: `npx nuxthub deploy`
6. Note the deployed URL

## Step 3: Update NUXT_PUBLIC_AUTH_URL

1. Go back to NuxtHub project settings → Environment Variables
2. Add/update `NUXT_PUBLIC_AUTH_URL` with your deployed URL (e.g., `https://recipe-remix-xyz.pages.dev`)
3. Redeploy (NuxtHub will auto-redeploy on env var changes)

## Step 4: Apply database migrations

1. In NuxtHub admin, go to Resources → Database
2. Open the D1 database console
3. Run migrations manually OR use NuxtHub's migration runner:
   ```bash
   npx nuxthub database migrate
   ```
4. Verify tables exist: Run `SELECT name FROM sqlite_master WHERE type='table';` in console

## Step 5: Seed production database

Option A (via seed endpoint):
```bash
curl -X POST https://your-app.pages.dev/api/_seed
```

Option B (via NuxtHub CLI):
```bash
npx nuxthub database execute "INSERT INTO ..."
# (run seed SQL statements)
```

- **Database errors**: Migrations not applied
- **No recipes**: Seed data not loaded
- **AI generation fails**: Workers AI not enabled in NuxtHub resources
- **Images don't load**: R2 bucket not configured or public access not enabled
