1. Install modules and utilities:
   ```bash
   npx nuxi@latest module add sitemap
   npx nuxi@latest module add schema-org
   ```
   These commands add the modules to `nuxt.config.ts` automatically. If they don't, manually add `'@nuxtjs/sitemap'` and `'nuxt-schema-org'` to the modules array.

   NOTE: Do NOT install nuxt-og-image. Per research recommendation, use existing R2 images via og:image meta tag (simpler, no extra module complexity). If a recipe has no image, use a generic fallback.

2. Update `nuxt.config.ts` with sitemap and schema-org configuration:
   ```typescript
   site: {
     url: 'https://recipe-remix-9fd.pages.dev',
     name: 'Recipe Remix'
   },
   sitemap: {
     sources: ['/api/__sitemap__/urls']
   },
   schemaOrg: {
     identity: {
       type: 'Organization',
       name: 'Recipe Remix',
       url: 'https://recipe-remix-9fd.pages.dev'
     }
   }
   ```
   Keep ALL existing config (hub, css, vite, devtools, future, compatibilityDate).

3. Create `server/api/__sitemap__/urls.ts`:
   - Use `defineSitemapEventHandler` from `#imports` (provided by @nuxtjs/sitemap)
   - Query D1 for all recipes: select slug, createdAt, featured
   - Map to sitemap URL objects: `{ loc: '/recipe/${slug}', lastmod: createdAt, changefreq: 'weekly', priority: featured ? 0.9 : 0.7 }`
   - Also include static pages: `{ loc: '/', changefreq: 'daily', priority: 1.0 }`
   - Use `useDrizzle(event)` with relative import (`../../utils/drizzle`)
   - NOTE: If `defineSitemapEventHandler` is not available, use a regular `defineEventHandler` that returns the URL array — the sitemap module can consume it either way. Check the module docs.

4. Create `server/utils/duration-formatter.ts`:
   - Export `minutesToISO8601(minutes: number): string`
   - Handle edge cases: 0 returns 'PT0M', negative returns 'PT0M'
   - Examples: 30 -> 'PT30M', 90 -> 'PT1H30M', 120 -> 'PT2H'

5. Create a generic fallback OG image at `public/og-default.png`:
   - This should be a simple 1200x630 branded image. Since we can't generate images in CLI, create a minimal SVG-based approach or just note that a placeholder is needed.
   - Actually, create `public/og-default.svg` as a simple branded fallback (1200x630 viewBox with "Recipe Remix" text and gradient background). SVG works for og:image.
   - If SVG doesn't work well for social cards, the executor can convert to PNG or use a solid color placeholder.

1. Update `app/pages/recipe/[slug].vue` — replace existing basic `useHead` with comprehensive SEO:

   a. Replace `useHead` with `useServerSeoMeta` (server-only, no client hydration overhead):
   ```typescript
   const siteUrl = 'https://recipe-remix-9fd.pages.dev'
   const slug = route.params.slug as string
   const recipeUrl = `${siteUrl}/recipe/${slug}`
   const ogImage = recipe.value.imageKey
     ? `${siteUrl}/api/images/${recipe.value.imageKey}`
     : `${siteUrl}/og-default.svg`

   useServerSeoMeta({
     title: `${recipe.value.title} | Recipe Remix`,
     description: recipe.value.description || `Delicious ${recipe.value.cuisineTags.join(' & ')} fusion recipe`,
     ogTitle: recipe.value.title,
     ogDescription: recipe.value.description || `Try this ${recipe.value.difficulty || 'delicious'} fusion recipe`,
     ogImage: ogImage,
     ogType: 'website',
     ogUrl: recipeUrl,
     twitterCard: 'summary_large_image',
     twitterTitle: recipe.value.title,
     twitterDescription: recipe.value.description || `Delicious fusion recipe from Recipe Remix`
   })
   ```

   b. Add canonical URL via `useHead`:
   ```typescript
   useHead({
     link: [{ rel: 'canonical', href: recipeUrl }]
   })
   ```

   c. Add Recipe structured data with `useSchemaOrg`:
   ```typescript
   import { minutesToISO8601 } from '~/server/utils/duration-formatter'
   // NOTE: If importing from server/ doesn't work in pages, inline the function or create a shared composable

   useSchemaOrg([
     defineRecipe({
       name: recipe.value.title,
       description: recipe.value.description || undefined,
       image: ogImage,
       author: { '@type': 'Organization', name: 'Recipe Remix' },
       datePublished: recipe.value.createdAt,
       cookTime: recipe.value.cookTime ? minutesToISO8601(recipe.value.cookTime) : undefined,
       totalTime: recipe.value.cookTime ? minutesToISO8601(Math.ceil(recipe.value.cookTime * 1.3)) : undefined,
       recipeYield: `${recipe.value.servings} servings`,
       recipeCategory: recipe.value.cuisineTags?.[0] || 'Fusion',
       recipeCuisine: recipe.value.cuisineTags?.join(', ') || 'Fusion',
       recipeIngredient: recipe.value.ingredients.map(i => `${i.quantity} ${i.unit} ${i.name}`.trim()),
       recipeInstructions: recipe.value.instructions.map((step, i) => ({
         '@type': 'HowToStep',
         position: i + 1,
         text: step
       })),
       keywords: [...(recipe.value.cuisineTags || []), ...(recipe.value.dietaryTags || [])].filter(Boolean).join(', '),
       aggregateRating: recipe.value.avgRating ? {
         '@type': 'AggregateRating',
         ratingValue: recipe.value.avgRating,
         reviewCount: recipe.value.totalReviews
       } : undefined
     })
   ])
   ```

   IMPORTANT: The `minutesToISO8601` function may not be importable from `server/utils/` in a page component. If so, create a shared utility at `app/utils/duration-formatter.ts` or inline the function. Do NOT use `iso8601-duration` package — the simple helper function is sufficient.
