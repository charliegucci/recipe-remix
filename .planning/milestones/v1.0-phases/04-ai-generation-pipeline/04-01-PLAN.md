  <action>
Create server/utils/ingredient-validation.ts that validates AI-generated ingredient names against the canonical `ingredients` (ingredientMaster) table in D1.

Export a function `validateIngredients(db: Database, aiIngredients: Array<{name: string, quantity: string, unit: string}>)` that returns `{ valid: boolean, resolved: Array<{name, quantity, unit, ingredientId, canonicalName}>, unresolved: string[] }`.

Matching logic (for each AI ingredient name):
1. Exact match (case-insensitive) on ingredients.name
2. Substring match both directions (e.g., "chicken breast" matches "chicken", "chicken" matches "chicken breast") -- same logic used in match-pantry.get.ts
3. Check commonNames JSON array (parse and case-insensitive match)
4. If no match found, add to unresolved list

If ANY ingredient is unresolved, return `valid: false` with the full unresolved list. This implements SAFE-01 and SAFE-04.

Use the useDrizzle pattern with relative imports (../../utils/drizzle). The function accepts the db instance as a parameter so it can be called from any handler.

Load all ingredients from DB once per validation call (there are ~305 items, fits in memory). Cache in a module-level variable with 5-minute expiry to avoid repeated DB reads.

  <action>
**food-safety.ts (SAFE-03):**

Export a constant `PROTEIN_SAFETY_MAP` mapping protein keywords to USDA safe temperatures:
- beef/veal/lamb/pork (steaks, chops, roasts): 145F/63C + 3 min rest
- ground beef/pork/veal/lamb: 160F/71C
- chicken/turkey/duck/poultry: 165F/74C
- ground poultry: 165F/74C
- fish/shrimp/crab/lobster/shellfish: 145F/63C
- eggs: 160F/71C

Export a function `injectSafetyTemps(instructions: string[], ingredients: Array<{name: string}>)` that:
1. Scans ingredient names for protein keywords (case-insensitive)
2. For each detected protein, finds the relevant cooking step (steps mentioning that protein or "cook", "bake", "grill", "roast", "fry")
3. Appends a safety note to that step: "Safety Note: {protein} should reach an internal temperature of {temp_F} ({temp_C}) for food safety."
4. Returns the modified instructions array

**dietary-check.ts (SAFE-02):**

Export a `RESTRICTION_MAP` constant mapping dietary restrictions to excluded ingredient categories/keywords:
- vegetarian: exclude meat, poultry, fish, shellfish keywords
- vegan: exclude all animal products (meat, poultry, fish, dairy, eggs, honey)
- gluten-free: exclude wheat, barley, rye, flour (unless rice/almond flour), pasta, bread
- dairy-free: exclude milk, cheese, butter, cream, yogurt
- nut-free: exclude almond, walnut, pecan, cashew, peanut, pistachio, hazelnut, macadamia

Export a function `checkDietaryRestrictions(ingredients: Array<{name: string}>, restrictions: string[])` that returns `{ passed: boolean, violations: Array<{ingredient: string, restriction: string}> }`.

For each restriction, check each ingredient name against the excluded keywords. If any match, add to violations. Return passed: false if any violations exist.
  </action>

  </verify>
